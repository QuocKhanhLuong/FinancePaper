# Round 2 gate: conditional numerical pilot only

Decision recorded 2026-10-05 before implementation/results. Base read:
`da7a0f1b3cad815b6c57c0f2a2c6287819be7fda`, branch
`research/method-pivot`. No historical test is opened for selection.

**CONDITIONAL GO** for exactly one bounded numerical feasibility study:
observation-specialized integration of fixed-background tree attribution moments.
**NO-GO** for claiming a novel SHAP compiler, statistical estimator, or financial
prediction method at this stage. This decision does not certify sufficient
novelty for a paper.

Two independent research reviewers agreed that the rectangle coefficient
identity is valid, that original prediction leaves are insufficient, and that
WOODELF/WOODELF-HD/FourierSHAP preclude claiming path compilation as new. Both
allowed a small experiment on the narrower conditional joint-moment endpoint.
They identified quadratic pair cost, correlated-law inference, compilation
amortization, and completion misspecification as decisive risks.

The selected mechanism and reduction tests are in [the method card](ROUND2_METHOD_SPEC.md).
The [prospective protocol](ROUND2_PREREGISTRATION.md) is frozen before code.
This is an algorithm feasibility test, not a claim that a numerical speedup
alone establishes methodological novelty. If the same operation is a direct
standard lifting of prior compilation/integration, correctness alone cannot
pass the method-paper gate.

The pilot must run the author's WOODELF implementation with its HD path, or mark
the strong-baseline gate incomplete. Record the exact official source revision,
MIT license, installed versions, and any adaptation. Include compilation costs
and finite-support enumeration. No invented financial AP/calibration gains:
the frozen predictor is unchanged by this inference primitive.

Audit correction, prediction-invisible linear identification, and response-space
distillation were rejected as method claims in [the research log](ROUND2_RESEARCH_LOG.md).
They are not implemented. The old first-round NO-GO remains visible.

If this pilot fails, retain the counterexamples, oracle, and negative results;
do not tune the synthetic generator or turn an unrun experiment into a failure.
